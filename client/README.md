# HR Chat Agent - frontend

React + TypeScript + Vite chat UI for the backend in `../server.js`. See the root `README.md`'s "Step 8" section for the full picture (architecture, how this talks to the API, the agent activity panel).

```bash
npm install
npm run dev     # dev server at http://localhost:5173, proxies /api to http://localhost:3001
npm run build   # outputs to dist/ - server.js serves this directly when it exists
```
